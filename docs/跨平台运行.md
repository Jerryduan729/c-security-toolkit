# 跨平台运行与打包

三种用法按环境选一种即可：

| 方式 | 需要 Python | 适合 |
| --- | --- | --- |
| 解压即用的分发包 | 不需要 | 交作业、演示、没有 Python 的电脑 |
| 源码运行 | 3.10+ | 自己改规则、看代码 |
| 自行打包 | 3.10+ 与 PyInstaller | 想要自己的平台专属版本 |

## 下载哪个包

在 [Releases](https://github.com/Jerryduan729/c-security-toolkit/releases/latest) 页面下载对应压缩包：

| 平台 | 压缩包 | 解压后主要文件 | 架构 |
| --- | --- | --- | --- |
| macOS | `SecurityToolkit-版本-macos-arm64.zip` | `启动网页版.command`、`security-scan` | Apple Silicon |
| Windows | `SecurityToolkit-版本-windows-x64.zip` | `启动网页版.bat`、`security-scan.exe` | x64 |
| Linux | `SecurityToolkit-版本-linux-x64.tar.gz` | `start-web.sh`、`security-scan` | x86_64 |

压缩包里带 `使用说明.txt`，内容和本文一致。下载后可用 `SHA256SUMS.txt` 校验。

> 为什么发压缩包而不是单个可执行文件？浏览器下载会丢掉可执行权限、还会附加 macOS 隔离属性，
> 裸文件双击必然没反应。压缩包能保留权限位，并附带启动脚本。

## 一、macOS（Apple Silicon）

### 1.1 解压与首次打开

1. 双击 zip 解压，得到 `SecurityToolkit` 文件夹（建议拖到「应用程序」或任意固定位置）
2. 双击文件夹里的 **`启动网页版.command`**
3. 若提示「无法验证开发者」或「已损坏，无法打开」，任选一种放行：

   - 右键点 `启动网页版.command` → 打开 → 再点「打开」
   - 打开「终端」，执行 `xattr -dr com.apple.quarantine SecurityToolkit`，再双击
   - 系统设置 → 隐私与安全性 → 找到被拦截的提示 → 仍要打开

放行一次即可，之后双击就能直接启动。浏览器会自动打开 `http://127.0.0.1:8765`。

> 启动脚本会自动补齐执行权限并清除隔离属性，所以只要它能被允许运行一次，后续都正常。

### 1.2 命令行用法

```bash
cd SecurityToolkit
./security-scan --version
./security-scan --authorized --source ./你的代码目录
./security-scan --authorized --source ./src --ai
```

AI Key 从环境变量读取：

```bash
export SECURITY_AI_API_KEY=sk-xxxx
./security-scan --authorized --source ./src --ai
```

### 1.3 架构说明

发布的是 **arm64** 版本，只能在 M1/M2/M3/M4 等 Apple Silicon 上运行。
Intel Mac 请用源码运行，或在 Intel 机器上自行打包（见第五节）。

> 这个版本在 Apple Silicon 本机构建（CI 的托管 macOS 运行器当前不可用）。

## 二、Windows（x64）

### 2.1 解压与首次打开

1. 右键 zip → 「全部解压缩」，得到 `SecurityToolkit` 文件夹（不要直接在压缩包里运行）
2. 双击 **`启动网页版.bat`**
3. 若出现蓝色 SmartScreen 窗口：点「更多信息」→「仍要运行」

程序没有代码签名，这不是病毒。杀毒软件误报时（PyInstaller 单文件常见），把文件夹加入白名单，
或改用源码运行。浏览器会自动打开 `http://127.0.0.1:8765`。

### 2.2 命令行用法（cmd / PowerShell）

```bat
cd /d D:\SecurityToolkit
security-scan.exe --version
security-scan.exe --authorized --source D:\code\myproject
security-scan.exe --authorized --source . --format markdown --output report.md
```

PowerShell 里路径含空格要加引号：

```powershell
.\security-scan.exe --authorized --source "C:\Users\me\Documents\我的代码"
```

### 2.3 环境变量

```bat
set SECURITY_AI_API_KEY=sk-xxxx
set SECURITY_AI_BASE_URL=https://api.deepseek.com/v1
set SECURITY_AI_MODEL=deepseek-chat
security-scan.exe --authorized --source . --ai
```

PowerShell：

```powershell
$env:SECURITY_AI_API_KEY = "sk-xxxx"
```

### 2.4 中文输出

程序启动时会把标准输出切到 UTF-8，中文不会乱码或崩溃。
如果旧版终端仍显示乱码，先执行 `chcp 65001` 再运行。

## 三、Linux（x86_64）

```bash
tar -xzf SecurityToolkit-版本-linux-x64.tar.gz
cd SecurityToolkit
./start-web.sh                       # 网页界面
./security-scan --authorized --source ./src
```

动态链接 glibc，主流发行版（Ubuntu 20.04+、Debian 11+、CentOS Stream 9+）可直接运行。

---

## 四、从源码启动

已经装了 Python 3.10+ 的话，不需要打包：

```bash
# macOS / Linux
./run.sh
python3 security_scan.py --authorized --source examples
```

macOS 也可以在 Finder 里双击 `启动-macos.command`（首次同样需要右键 → 打开）。

Windows 双击 `启动-windows.bat`，脚本会自动找 `py -3` 或 `python`：

```bat
py -3 web_app.py --open
```

## 五、自行打包

三个平台用同一套配置，各平台各自打包（PyInstaller 不支持交叉编译）：

```bash
python3 -m pip install pyinstaller        # 或 python3 packaging/build.py --install
python3 packaging/build.py                # 产出 dist/ 下的可执行文件
python3 packaging/package.py --version 1.2.1   # 整理成 release/ 下的压缩包
```

| 脚本 | 作用 |
| --- | --- |
| `packaging/build.py` | 调 PyInstaller，产出两个单文件程序 |
| `packaging/package.py` | 加上启动脚本与说明，打成 zip / tar.gz |
| `packaging/security_toolkit.spec` | 打包配置（两个入口、内嵌网页资源） |

也可以在 GitHub 上手动触发：仓库 → Actions → build → Run workflow，
跑完在 Artifacts 里下载对应平台的压缩包。打 `v*` 标签时会自动构建 Windows 与 Linux 版本。

## 六、常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| macOS 双击没反应 | 下载的裸文件没有执行权限 | 用压缩包分发；或 `chmod +x 文件名` |
| macOS 提示「已损坏，无法打开」 | 未签名 + 隔离属性 | `xattr -dr com.apple.quarantine SecurityToolkit` |
| macOS 提示「无法验证开发者」 | 同上 | 右键 → 打开 → 再点「打开」 |
| `bad CPU type in executable` | 在 Intel Mac 上跑 arm64 版本 | 用源码运行，或自行打包 |
| Windows 蓝色 SmartScreen | 无代码签名 | 更多信息 → 仍要运行 |
| Windows 提示「找不到应用」 | 直接在压缩包里双击 | 先全部解压缩再运行 |
| 杀毒软件报毒 | PyInstaller 单文件常见误报 | 加白名单，或改用源码 |
| 双击 `.bat` 闪退 | 没装 Python 或路径含特殊字符 | 在该目录打开 cmd 手动执行看报错 |
| 网页打不开 | 端口被占用 | `--port 8800` 换端口 |
| 报告找不到 | 写在程序同级的 `reports/` | 去 `SecurityToolkit/reports/` 找 |
| Linux 报 `GLIBC_2.xx not found` | 系统过旧 | 用源码运行，或在目标系统上自行打包 |

## 七、校验下载是否完好

```bash
shasum -a 256 -c SHA256SUMS.txt      # macOS；Linux 用 sha256sum -c
```

解压后也可以直接验证：

```bash
./security-scan --version       # 应输出 Security Toolkit 1.2.1
./security-scan --list-rules    # 应列出 17 条规则
```

再跑一次 `--authorized --source examples`，应得到 9 条结果、退出码 1。
